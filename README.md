# bookmarklets
Useful bookmarklets collection:

1. Extract text in All Forms on current webpage (take a copy of all you entered into some forms, e.g. when registered new user or during polls answers, etc.)
2. Download all text from current webpage (take a comprehensive text dump of all contents)
3. Mirror video in first found player (useful when watching selfie-cam videos where everything was mirrored during recording)
4. Show passwords (all password fields become visible, useful for visual control of fields contents)
5. ...


















# How they was made?
All them was made by simple prompting in Deepseek chat
